# Roadmap

## Versão 1.0 - MVP Funcional

- [x] Interface em Dark Mode.
- [x] Entrada de conceito do personagem.
- [x] Seleção de estilo visual.
- [x] Geração textual da ficha.
- [x] Geração de avatar.
- [x] HP, MP e XP interativos.
- [x] Calculadora de dados.
- [x] Abas de lore, habilidades, equipamentos e JSON.
- [x] Exportação em PDF via navegador.

- [ ] Separar HTML, CSS e JS do MVP monolítico.
- [ ] Melhorar responsividade em telas pequenas.
- [ ] Criar tutorial guiado para novos usuários.
- [ ] Adicionar validação visual da chave de API.
- [ ] Criar mensagens de erro mais amigáveis.
