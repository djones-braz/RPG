# Guia do Usuário

## Objetivo

Este guia explica como usar o **AI Lore & Character Sheet Studio** para criar personagens de RPG com apoio de IA.

## Passo a passo

### 1. Abrir o MVP

Na página do projeto, clique em **Abrir MVP Funcional**.

### 2. Configurar a chave da API

Clique em **Configurações** e insira sua chave gratuita do Google AI Studio.

A chave é salva apenas localmente no navegador.

### 3. Descrever o personagem

No campo **Palavras-Chave / Conceito**, descreva o personagem em até 500 caracteres.

Exemplo:

```text
Guerreiro cibernético, melancólico, mestre em espadas laser, de poucas palavras.
```

### 4. Escolher o estilo visual

Selecione um estilo de avatar:

- Concept Art;
- Anime/Manga;
- Pixel Art;
- Realista;
- Cyberpunk Neon;
- Pintura a Óleo.

### 5. Gerar ficha e avatar

Clique em **Gerar Ficha & Avatar** e aguarde a resposta da IA.

### 6. Usar a ficha durante a partida

A ficha permite:

- aplicar dano e cura;
- gastar e recuperar mana;
- ganhar ou perder XP;
- alterar atributos;
- usar equipamentos;
- rolar dados;
- copiar JSON;
- exportar PDF.

### 7. Usar a calculadora de dados

Digite fórmulas como:

```text
1d20 + FOR
2d6 + DES
1d100
```

Os modificadores são calculados com base nos atributos do personagem ativo.

## Dicas

- Use descrições curtas e específicas.
- Teste estilos diferentes para o mesmo personagem.
- Copie o JSON bruto para reutilizar dados em outras ferramentas.
- Exporte a ficha em PDF para uso offline.
