# Metodologia de Desenvolvimento

O projeto foi construído com abordagem ágil e incremental, priorizando um MVP funcional que pudesse ser compreendido, testado e apresentado pela comunidade acadêmica.

## Etapas

| Etapa | Objetivo | Resultado |
|---|---|---|
| 1. Planejamento | Identificar problema, público e proposta de valor | Definição do escopo do MVP |
| 2. Modelagem e regras | Mapear atributos, status e modificadores | Estrutura básica da ficha |
| 3. Integração de texto | Criar prompt e schema JSON | Geração de personagem por IA |
| 4. Integração visual | Conectar geração de avatar | Ficha com imagem conceitual |
| 5. Validação e testes | Testar calculadora, ficha e exportação | MVP demonstrável |

## Natureza educacional

O MVP foi desenvolvido como exercício prático de aplicação de IA Generativa em produto digital, envolvendo:

- design de interface;
- engenharia de prompts;
- integração com APIs;
- documentação técnica;
- prototipação web;
- apresentação pública via GitHub Pages.
