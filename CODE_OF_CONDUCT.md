# Código de Conduta

Este projeto é acadêmico, educacional e aberto à comunidade. Espera-se que todos os participantes mantenham respeito, colaboração e linguagem adequada.

## Compromissos

- Tratar estudantes, professores, usuários e colaboradores com respeito.
- Apresentar críticas de forma construtiva.
- Não publicar conteúdo ofensivo, discriminatório ou incompatível com ambiente educacional.
- Preservar os créditos dos desenvolvedores e da orientação docente.

## Aplicação

Contribuições que violem este código podem ser recusadas ou removidas.
