# Como contribuir

Obrigado pelo interesse em contribuir com o **AI Lore & Character Sheet Studio**.

## Formas de contribuição

- Corrigir erros de interface ou responsividade.
- Melhorar a documentação técnica.
- Criar novas inspirações rápidas de personagens.
- Criar novos estilos visuais de avatar.
- Melhorar a calculadora de dados.
- Propor integração com VTTs, como Roll20 ou Foundry VTT.
- Traduzir a interface ou adaptar para outros sistemas de RPG.

## Padrão de contribuição

1. Abra uma issue descrevendo a melhoria ou problema.
2. Faça um fork do repositório.
3. Crie uma branch com nome claro, por exemplo: `feature/novos-estilos`.
4. Faça commits pequenos e descritivos.
5. Abra um Pull Request explicando o que foi alterado.

## Boas práticas

- Preserve a autoria acadêmica do projeto.
- Evite expor chaves de API no código.
- Teste em desktop e celular.
- Mantenha a aplicação como projeto estático compatível com GitHub Pages.
